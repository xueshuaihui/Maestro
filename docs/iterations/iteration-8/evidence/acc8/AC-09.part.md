## 备注

- kill 用 core.json.pid + SIGKILL（等价 taskkill /F /PID）；冷启动用 `orch status`（instance.list 只读）避免 instance.get 健康度写与恢复 saveState 的 CAS 冲突。不使用 recovery-driver 自带的恢复流程，因其 runStatus 用 status --instance 触发恢复会随机丢失 recoveredAt，且取证后 core.stop 会把 running 改为中断。
