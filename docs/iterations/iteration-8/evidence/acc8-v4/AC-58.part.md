- e2e 夹具改用 pass 图（T-001 开发 / T-002 测试一次通过）：backflow 图首轮故意 fail，会触发「回流重测 T-001」，把已完成节点二次派发，与 C06/C07「不重跑」断言冲突；pass 图在状态驱动 kill 命中的窗口恢复后直接走到终态，不篡改任何事件或状态。人工节点组按需求 Given 用 test/fixtures/recovery/human-node-state.json 另起独立项目根预置。
- driver 收尾 core.stop 会把实例改写为「已中断」，-driver 之后的 CLI 再冷启动还会继续推进；所有判定取 driver 在 stop 之前落下的 recoveryStatus / afterRecovery / events / prompt-log。
- driver 恢复后 --wait-ms=20000 用状态轮询等「完成/升级」终态（到点即停，非固定 sleep）；实测 afterTerminal.state="completed"，terminalWait={"mode":"poll","terminal":true,"waitedMs":419,"finalState":"completed"}。C02/C10 等恢复时刻判定取 afterRecovery，C13 取 afterTerminal，断言表达式逐字不变。
