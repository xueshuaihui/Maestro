## §1 范围（In / Out）

**一句话目标**：把「角色流程图看见红点」到「弄清楚为什么、处理掉、让它继续跑」补齐——点角色进下钻（状态栏 + 1 跳局部 DAG + 任务卡片）、点卡片看会话时间线与证据、点连接线看交接包明细、点人工/升级节点直达处置、子工作流逐层下钻、一键唤起 DSH 并给出可核对（剪贴板 + 等于 `state.sessions[].sessionId`）的会话标识；全程不需要终端。

**In scope**（逐条对应需求 §1.3「范围内」11 条）：
1. 角色下钻视图（状态栏五项 + 局部 DAG 1 跳 + 卡片列表，返回后流程图状态不丢）→ §2.2~§2.4，AC-01/02/05/38。
2. 任务卡片（三层 + 6 态会话指示器 + 节点类型特殊显示 + 耗时换算）→ §2.5，AC-07/08/09/10/35。
3. DAG 与卡片联动（滚动 + 高亮，零死链）→ §2.6，AC-06。
4. 节点详情层（四段：时间线 / ACP 摘要 / 证据引用 / 交接包历史，空态齐全）→ §2.7，AC-11~15。
5. 「查看全部节点」切换（复用 I1.10a 7 列看板，原路返回下钻）→ §2.8，AC-16。
6. 子工作流下钻（逐层 + 逐级返回 + 三种降级）→ §2.9，AC-17/18/36。
7. 连接线点击（交接包列表 + 每包时间线 + 历史轮次）→ §2.10，AC-19/42/43。
8. 特殊节点交互（人工节点 → 详情；升级节点 / `escalated` 角标 → 本实例升级面板）→ §2.11，AC-20/21/49。
9. 升级处理闭环（唯一动作「继续」，经既有 `resolveEscalation` 的 retry 语义）→ §2.12，AC-22/23/24/44/45。
10. 一键跳转宿主会话（裁决 A 三段口径 + 裁决 I 核对方式 + 四种降级）→ §2.13，AC-25/26/33/46。
11. 下钻层实时性与只读（2 秒内更新、会话变化不重排、浏览全程只读）→ §2.14，AC-27/28/47/48/50。

**Out of scope 摘要**（逐项有归属，全表见需求 §1.3）：
- 通知、跨实例人工干预队列、审批裁决、重派/终止、角色/技能/工作流库浏览、工作流画布、证据浏览独立视图、托盘增强 → **I1.11**（`docs/index.md` 878–888）。
- 证据过期检测、产物指纹校验、权限拦截、预算配额、生态能力、性能基线（≥20 实例等）→ **I1.12**（892–907）。
- 多宿主跳转（Cursor / GPT / WorkBuddy）、Web 远程查看 → **I2.4**（952–960）。
- 按会话自动定位（深链）：**规划不可达**，主控裁决 A 定案（DSH 0.2.2-rc.1 无会话级深链），不是需求收窄。
