## 本机/技术硬事实（I1.11+ 必守）

1. **Tauri 2 外部 http origin 没有 IPC**：WebView 导航到 `http://127.0.0.1:<port>/ui/` 后，`window.__TAURI__` / `__TAURI_INTERNALS__.invoke` 均不存在，即使 `app.withGlobalTauri=true` 也一样；本地 `tauri-2.12.5` 源码确认 v2 已移除远程域 IPC 配置。因此窗口→壳的事件必须走 HTTP 镜像：页面 `POST /__test__/window-probe`（仅 `NODE_ENV=test`、Bearer）→ daemon append `<root>/.orch/window-probe.jsonl` → 壳 `probe.rs` 100ms 轮询原样搬运到 `--probe`。事件内容仍由窗口渲染层产出，壳不合成。
2. **桌面构建必须 `env -u NODE_OPTIONS npm run desktop:build`**：平台注入的 `NODE_OPTIONS` safe-delete shim 会拦截 `build.mjs` 的 `fs.rmSync(APP)`（bulk-delete 62 > 阈值 50）导致 `BUILD_EXIT=1`；去掉注入后增量构建约 31~46s。`cargo check` 与全量测试同样建议 `env -u NODE_OPTIONS`。
3. **boot 对账会改写预置 `state.json`**：空根预置实例快照再起 `serve-entry --desktop`，`desktop.json` 正常落盘但 state 前后字节不等。窗口面夹具必须「先起壳 → ready → 再写 fixtures → ctl `tray-open` 触发窗口 refresh-list」。
4. **ctl 触发物是目录**：`runCtl` 用 `mkdirSync`，清理 `.done` 必须 `fs.rmSync(..., {recursive:true, force:true})`，否则第二次重试报 `EISDIR`。
5. **Bash 里的 `grep` 在本环境常被 shim 干扰返回空/0**：核文件内容优先用 Grep 工具或 Python `open().read()`，别用 Bash grep 下结论。
6. 全量判定一律 `env -u NODE_OPTIONS NODE_ENV=test node --test --test-concurrency=1 "test/**/*.test.js"`；默认并发会假 flake。基线判定 9 条（物理 8 + R-08 允许的 AC-04）。
