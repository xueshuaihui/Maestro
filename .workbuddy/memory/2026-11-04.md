## 关键坑（必读）

1. **`-32602` 同码双义**（DSH）：既表示「会话不存在/已关闭」，也表示「已有 prompt 在飞行」。按 code 判会话失效会导致「目标忙 → 误判会话没了 → 新建重复会话 → 交接重复执行」。必须按 message 细分或 `session/list` 回读。
2. **本机 `ELECTRON_RUN_AS_NODE=1` 常驻**：直接跑 electron 会退化成纯 Node（`require('electron')` 返回路径字符串，`app` 为 undefined）。`smoke.mjs` 里已 `delete env.ELECTRON_RUN_AS_NODE`。
3. **Electron 二进制走 GitHub 下载会卡死**（5 分钟只拿到 1.1MB）；用 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后 11 秒装完（326MB）。
4. mock 新增开关：`--accept-delay-ms`、`--busy-policy=error|queue`、`--noise-on-session-new`、`--noise-delay-ms`、`--noise-at-turn-end`（默认全关，不影响既有实验）。
