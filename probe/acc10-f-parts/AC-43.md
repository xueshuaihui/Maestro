## ① 判据原文（逐字，不放宽）

**Given** 某次构建有一个平台失败、另两个平台成功；或同名 tag 的 Release 已经存在。

**When** 维护者修复后重跑，或对同名 tag 再推一次。

**Then**

- Releases 页始终只有该版本**一个**条目；重跑是更新/补齐这个条目的资产，不是新建第二个；三个平台产物最终齐全；同一时刻两次触发不会互相覆盖出半套资产。

**机检**：`test -f test/wp13/release-contract.test.js && NODE_ENV=test node --test test/wp13/release-contract.test.js` 静态断言「已存在则补传、否则创建」的分支、覆盖式上传、以及同版本并发互斥；`node probe/acc10-release-verify.mjs <tag> --check idempotent` 断言远端同名 Release 计数为 1 且资产齐全。

**夹具**：构造一次单平台失败的试跑后重跑；保留两次构建记录。

**架构检查**：任一平台失败不得阻塞其它平台产出自己的产物（不因一红全停）；但汇总发布必须等全部平台成功，缺一不发。
